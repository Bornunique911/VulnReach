Planned Auth Strategy

VulnReach v2 will support two authentication modes:

Browser / Human Access
Google SSO (OAuth 2.0)
Sign in with your Google workspace account. Session tokens stored in HttpOnly cookies. Refresh tokens handled server-side.
API / Machine Access
API Keys or JWT Bearer tokens
Long-lived API keys for CI/CD pipelines. Short-lived JWT bearer tokens for service-to-service. Scopes: scan:write scan:read.
# Example API key usage
curl -H "Authorization: Bearer <API_KEY>" \
     -X POST https://vulnreach.internal/scan \
     -d '{"repo_path":"/app","config_path":"/app/vulnreach.yaml"}'
