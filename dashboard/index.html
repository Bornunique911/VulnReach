Authentication options for programmatic access

JWT Authentication

VulnReach v2 uses JWT bearer tokens. Obtain a token via POST /login, then pass it in the Authorization header.

Browser / Dashboard
Sign in via the dashboard
Click "Sign in" in the top bar. Token is stored in-memory for the session.
API / Machine Access
JWT Bearer tokens
Short-lived JWT tokens for CI/CD and service-to-service. Roles: admin analyst.
# 1. Get a token
curl -X POST http://localhost:8000/login \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"changeme"}'
# 2. Use the token
curl -H "Authorization: Bearer <TOKEN>" \
     http://localhost:8000/scans
